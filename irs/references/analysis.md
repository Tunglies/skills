# Analysis Mode

Use only without edit authorization. Do not edit, commit, or start an implementation writer.

Inspect enough repository evidence to ground the canonical contract. Mark unknowns. Present only populated contract sections, plus credible options, verification, review routing, and material pending decisions.

Use an option matrix only for two or more credible shapes. Prefer the smallest shape meeting the behavior contract, not the fewest lines.

If an option exceeds budget, explain why. Record expansion without another question only when it stays inside the request and adds no behavior, public contract, ownership boundary, or external side effect; otherwise leave a pending decision.

End with recommendations and the next authorization gate. If the same request already authorized edits, route it as Implement instead.
